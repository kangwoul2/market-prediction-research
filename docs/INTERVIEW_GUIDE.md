# 시장 방향 예측 연구 면접 가이드

모든 답변은 **문제 → 원인 → 대안 → 선택 → 단점 → 검증** 순서로 설명합니다.

## 1. 무엇을 예측한 연구인가요?

내일의 Bitcoin 가격 자체를 숫자로 맞히는 회귀 문제가 아니라 다음 날 수익률을 기준으로 방향을 분류하는 문제입니다.

```text
다음 날 수익률 > +1%  → 상승
-1% ~ +1%             → 횡보
다음 날 수익률 < -1%  → 하락
```

±1%는 기존 연구에서 작은 움직임과 비교적 큰 움직임을 나누기 위해 사용한 고정 기준이며 최적값이라고 주장하지 않습니다.

## 2. 기존 딥러닝 모델은 과거 며칠을 봤나요?

LSTM, GRU, Transformer 모두 `sequence_length = 60`으로 **과거 60일을 보고 다음 날 방향을 예측**했습니다. 60일이 최적이라고 검증한 것은 아니며, 다시 연구한다면 30·60·90일 등 여러 기간을 검증 데이터에서 비교해야 합니다.

## 3. 기존 연구 결과를 왜 그대로 신뢰하기 어렵다고 판단했나요?

모델 점수보다 평가 방식을 다시 봤습니다. 기존 코드에서는 전체 데이터로 표준화 기준을 계산한 뒤 시간을 섞어 학습·테스트 데이터를 나눴습니다. 금융 시계열의 실제 사용은 과거로 미래를 예측하는 구조이므로 모델을 더 조정하기 전에 평가 방식을 먼저 수정했습니다.

## 4. 왜 시계열에서 무작위 분할이 문제인가요?

무작위 분할에서는 미래 시점의 데이터가 학습 데이터에 들어가고 더 과거 시점의 데이터가 테스트에 들어갈 수 있습니다. 실제 서비스에서는 사용할 수 없는 미래 정보가 학습 과정에 영향을 줄 수 있으므로 시간 순서대로 나누는 편이 더 타당합니다.

## 5. 표준화도 데이터 누수를 만들 수 있나요?

네. 전체 데이터의 평균과 분산으로 표준화 기준을 계산하면 미래 테스트 구간의 분포 정보가 학습 전처리 기준에 들어갑니다. 그래서 학습 데이터에서만 기준을 계산하고 검증·테스트에는 그 기준을 그대로 적용합니다.

## 6. 왜 정확도 외에 균형 정확도와 Macro F1을 같이 봤나요?

상승·횡보·하락 비율이 같지 않으면 가장 많은 클래스만 잘 맞혀도 정확도가 높게 나올 수 있습니다. 균형 정확도는 클래스별 재현율을 같은 비중으로 보고, Macro F1은 각 클래스의 F1을 같은 비중으로 봅니다.

## 7. 3개 클래스인데 정확도 40%가 의미가 있나요?

40%만 보고 의미 있다고 판단하지 않습니다. 같은 테스트 구간에서 다수 클래스를 계속 예측하는 기준 모델의 정확도는 29.30%, Macro F1은 15.11%였습니다. BTC 단독 ExtraTrees는 정확도 40.00%, Macro F1 38.44%였습니다. 따라서 같은 평가 조건의 단순 기준보다 추가 신호가 있는지를 비교합니다.

균등하게 무작위로 3개 중 하나를 고르는 경우 기대 정확도는 약 33.3%지만, 실제 비교 기준은 학습 데이터의 다수 클래스를 계속 예측하는 모델입니다.

## 8. 기존 GRU 37.39%와 새 40.00%는 2.61%p 개선인가요?

그렇게 주장하지 않습니다. 기존 연구는 무작위 분할과 전체 데이터 전처리를 사용했고 V2는 시간 순 분할과 학습 데이터만을 이용한 전처리를 사용했습니다. 평가 조건이 다르기 때문에 직접적인 전후 개선율로 비교할 수 없습니다. V2의 의미는 더 엄격한 조건에서도 같은 조건의 기준 모델보다 높은 결과를 재현했다는 것입니다.

## 9. 왜 딥러닝 대신 ExtraTrees가 가장 좋았나요?

V2는 가격 수준보다 여러 상대값과 과거 수익률을 표 형태의 변수로 만든 실험입니다. 이런 데이터에서는 트리 계열 모델이 비선형 관계를 효율적으로 잡을 수 있습니다. 복잡한 모델을 우선하지 않고 검증 데이터에서 실제 성능이 좋은 모델을 선택했습니다.

## 10. 외부 시장 변수는 왜 넣었나요?

Bitcoin 움직임이 주식시장 위험선호, 업종 ETF, 금과 함께 움직일 수 있다는 가설을 확인하기 위해 사용했습니다. 설명만 붙이는 대신 BTC 단독 변수와 같은 문제에서 직접 비교했습니다.

## 11. 외부 시장 변수를 넣으면 좋아졌나요?

항상 그렇지는 않았습니다. 전체 날짜 3분류에서는 BTC 단독 Macro F1 0.3844가 외부 시장 포함 0.3772보다 높았습니다. 반면 ±1% 이상 움직인 날의 상승·하락 방향에서는 외부 시장 포함 Macro F1이 0.5451로 BTC 단독 0.5189보다 높았습니다. 따라서 변수의 효과는 예측 문제에 따라 달랐다고 해석합니다.

## 12. 확신도가 높은 구간만 예측한다는 것은 무엇인가요?

모델 확률이 낮을 때는 억지로 예측하지 않고 정한 기준 이상일 때만 결과를 사용하는 방식입니다. 정확도를 높여 보이게 하는 문제가 생길 수 있으므로 **정확도와 예측 범위를 반드시 함께 제시**합니다.

## 13. 64.63% 정확도는 어떤 의미인가요?

BTC 단독 큰 움직임 발생 여부 분류에서 확신도 0.65 이상인 **전체 테스트 표본의 약 23.1%만 선택했을 때**의 정확도입니다. 전체 날짜 정확도가 아닙니다. 따라서 예측 범위 23.1%, 균형 정확도 64.94%, Macro F1 64.20%를 함께 말합니다.

## 14. 시간 이동 검증은 왜 하나요?

한 번의 테스트 구간이 특정 시장 상황에 우연히 잘 맞았을 수 있기 때문입니다. 시간축을 앞으로 이동하면서 여러 구간을 평가해 평균 성능과 변동성을 확인합니다. 첫 V2 실험의 Macro F1 평균/표준편차는 0.3485/0.0198이었습니다.

## 15. 이 모델로 실제 투자할 수 있나요?

그렇게 주장하지 않습니다. 분류 정확도와 투자 수익률은 다릅니다. 거래비용, 슬리피지, 주문 체결 지연, 포지션 크기, 손실폭 등을 포함한 실제 매매 규칙과 백테스트가 추가로 필요합니다.

## 16. 연구에서 가장 크게 배운 점은 무엇인가요?

좋은 모델을 고르는 것보다 **좋은 평가 방식을 만드는 것이 먼저**라는 점입니다. 미래 정보 유입을 막고, 기준 모델과 비교하고, 실패한 변수 가설도 남기고, 한 번의 테스트 점수보다 시간에 따른 안정성을 함께 확인했습니다.

## 30초 답변

> 다음 날 Bitcoin 수익률이 +1%를 넘으면 상승, -1% 아래면 하락, 그 사이는 횡보로 정의한 3분류 연구입니다. 원래는 과거 60일을 입력으로 LSTM, GRU, Transformer를 비교했고 GRU 정확도가 37.39%였습니다. 이후 전체 데이터로 전처리 기준을 계산하고 시간을 섞어 데이터를 나눈 문제가 있다는 것을 확인했습니다. 그래서 V2에서는 시간 순으로 60/20/20을 나누고 전처리 기준도 학습 데이터에서만 계산했습니다. 같은 조건의 다수 클래스 기준 모델 정확도는 29.30%, BTC 단독 ExtraTrees는 40.00%였습니다. 핵심은 높은 숫자를 주장하는 것이 아니라 미래 정보 유입을 막고 기준 모델과 시간 이동 검증으로 결과를 다시 확인한 것입니다.
