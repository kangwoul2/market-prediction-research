## 중요한 주의점

이 표는 학사 연구 당시의 결과를 그대로 보존한 것입니다. 이후 코드 점검에서 전체 데이터로 전처리 기준을 계산하고 시간을 섞어 학습·테스트 데이터를 나눈 평가 방식이 확인됐습니다.

따라서 이 결과는 Research V2의 수치와 직접적인 전후 개선율로 비교하지 않습니다.

V2에서는 다음을 추가했습니다.

- 시간 순 학습/검증/테스트 분리
- 학습 데이터만 이용한 전처리 기준 계산
- 다수 클래스 기준 모델
- 균형 정확도와 Macro F1
- 시간 이동 검증
- 예측 범위와 확신도 비교

## 면접에서 연결할 점

평가 지표 하나만 보고 결론을 내리지 않는 원칙은 백엔드 성능 검증과도 같습니다.

```text
머신러닝
정확도 하나만 보지 않음
→ 균형 정확도 / Macro F1 / 기준 모델 함께 확인

백엔드
평균 지연시간 하나만 보지 않음
→ 처리량 / p95·p99 / 오류율 함께 확인
```

핵심은 **측정 지표를 실제로 줄이고 싶은 오류나 사용자 경험과 연결하는 것**입니다.
